# Colony image analysis of Oa and a collection of 28 partners in presence and absence of thiamin

This repository contains the code used to process and analyze colony images of Oa grown in co-culture with 28 partner strains on FA (with and without thiamin) medium, in 3 biological replicates. The standard FA condition was acquired in four rounds. For a subset of 8 partners, colonies were additionally imaged on FA medium without salt and on glucose medium.

**NAMING CONVENTION**

The files associated with the four data acquisition rounds in FA medium contain the strings SET1-SET4. The files associated with the FA medium without salt, and the glucose medium contain the strings NOSALT and GLUCOSE, respectively. The string AllSets_FA refers to the combination of the 4 sets of data acquired in FA medium. 

The D5 string on some of the files indicates that the images were imaged at day 5.

### CFU counts

`cfu_counts/raw_data/` contains the CFU counts of mono- and cocultures at day 0 and day 6 for each data of the 6 data acquisition rounds (4 rounds for FA, one round for NOSALT, one round for GLUCOSE).

*NOTE: All files are saved in .ods (Libre Office spreadsheet format), some of the are saved in .csv as well. Ideally we could only use one format!* 

### Raw data

The 6 subfolders within `raw_data/` contain the raw .czi files generated by the confocal imaging. Each subfolder contains a subfolder FullCols with one representative full colony image of Oa with partner in presence and absence of salt, and a subfolder CloseUps with the closeup images of each of the three replicates. 

### Processed data

The 6 subfolders within `processed_data/` contain, for each partner, condition (thiamin or no thiamin) and replicate, the ilastik probabilities (.h5 format) of closeup images and the normalized closeup image pre-generated in the analysis scripts. 

### Ilastik projects

Folder `ilastik_projects/FAT-FA` contains the ialstik project `AllCloseups.ilp` with which the pixel classification was trained. The raw data for the pixel classification was a subset of the closeup images collected in FA medium, with and without thiamin. The weights were used to generate all othe probbaility files stored in `processed_data/`.

## 4. Reproducing the analysis

To reproduce the analysis:

1. Clone this repository.
2. Download or obtain the associated data.
4. Set the data path to the appropriate location on your system as indicated under **3. Connecting the code to the data**
5. Create and activate the Conda environment followin the instructions under **Software environment**
6. Run the analysis scripts in the order described under **Analysis workflow**.

## Software environment

The Python environment required for the analysis can be created using:

```bash
conda env create -f colony_patterns.yml
conda activate colony_patterns
```

## Analysis workflow

1. Create probability masks for closeup images using ILASTIK  
2. For each of the three datasets (FA, NOSALT, GLUCOSE) create focus masks
3. For each of the three datasets (FA, NOSALT, GLUCOSE) calculate interactions, mixing and sector sizes
4. For each of the three datasets (FA, NOSALT, GLUCOSE) perform statistical analyses
5. Perform statistical analyses on the full dataset
   

| Step | Input | Script/software | Output |
|---|---|---|---|
| 1. Pixel classification | Raw microscopy images stored in `raw_data`| ilastik 1.4.0b21 | `.h5` probability maps stored in `processed_data` |
| 2. Create focus mask | Raw microscopy images stored in `raw_data` | ANALYSIS_FOLDER/`focus_masks_DATASET_LABEL.py` | focus masks stored in `processed_data` |
| 3. Calculate interactions, mixing and sector sizes | CFU data. focus masks and raw ilastik probabilities | `ANALYSIS_FOLDER/`DATASET_LABEL.ipypy` for NOSALT and GLU, `AllSets_FA/postprocess_FA.ipynb` for FA datasets | csv file stored in ANALYSIS_FOLDER |
| 4. Perform statistical analyses | csv file with interactions and image quantifcations | `ANALYSIS_FOLDER/analysis_DATASET_LABEL.ipypy`  | plots|
| 5. Perform statistical analyses on full dataset (4 FA datasets)| csv file with interactions and image quantifications| `AllSets_FA/mixed_effect_models_FA.ipynb` | plots|
| 6. Perform statistical analyses on full dataset| csv files with interactions and image quantifications for all datasets| notebooks in `FullData` | plots|
